## Pourquoi les consultants RH passent autant de temps sur PowerPoint

Dans les cabinets de conseil RH ou en freelance, les presentations sont au coeur de la relation client.
Chaque mission genere plusieurs supports :

- diagnostic initial
- restitution d'analyse
- recommandations strategiques
- plan d'action
- suivi de mission

Ces documents sont presque toujours presentes sous forme de slides PowerPoint.

Le probleme est que ces presentations doivent etre :

- claires
- structurees
- visuellement professionnelles

Et cela demande beaucoup de travail.

Un consultant RH doit souvent :

- structurer son raisonnement
- ecrire les contenus
- organiser les slides
- appliquer le design
- adapter les couleurs et la charte graphique du client

Meme pour un consultant experimente, cela peut prendre plusieurs heures pour une seule presentation.

## Les presentations RH les plus longues a creer

Certaines presentations sont particulierement chronophages pour les consultants RH.
Voici les plus frequentes.

### 1. Les diagnostics organisationnels

Ces presentations incluent souvent :

- analyse de l'organisation
- points de friction
- cartographie des roles
- recommandations

Ce sont des slides riches en contenu.

### 2. Les plans de transformation RH

Tres courants dans les missions de conseil.
Ils incluent generalement :

- vision strategique RH
- axes de transformation
- plan d'action
- roadmap

Ces presentations peuvent facilement depasser 30 slides.

### 3. Les presentations pour le comite de direction

Le niveau d'exigence est eleve.
Les slides doivent etre :

- synthetiques
- convaincantes
- structurees

Les consultants passent donc beaucoup de temps a peaufiner ces presentations.

### 4. Les feuilles de route RH

Ces presentations servent a montrer :

- les priorites
- le calendrier
- les projets RH

Elles demandent souvent beaucoup de structuration.

## Combien de temps un consultant RH passe vraiment sur PowerPoint ?

Un consultant RH realise en moyenne :
