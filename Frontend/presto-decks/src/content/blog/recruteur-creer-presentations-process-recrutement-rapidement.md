# Le guide du recruteur pour creer des presentations de process de recrutement rapidement

## Introduction

Un recruteur ne passe pas seulement son temps a sourcer et a mener des entretiens.

Il doit aussi presenter clairement :

- l'etat du pipeline de candidats
- les etapes du process de recrutement
- les retours d'entretien
- les besoins ouverts par equipe
- les priorites de recrutement

Et dans beaucoup d'organisations, tout cela finit dans PowerPoint.

Le probleme, c'est que ces presentations sont souvent repetitives et prennent trop de temps.

Il faut structurer l'information, synthetiser les retours, rendre les slides lisibles et adapter le message a des managers, a la direction ou a l'equipe RH.

Aujourd'hui, un [generateur PowerPoint IA](/generateur-powerpoint-ia) peut accelerer fortement cette partie.

Dans ce guide, nous allons voir :

- pourquoi les presentations RH et recrutement prennent autant de temps
- quels supports sont les plus chronophages
- comment utiliser SlideAI pour produire plus vite des decks de recrutement clairs

## Pourquoi les presentations de recrutement prennent autant de temps

Une presentation de recrutement ne consiste pas a copier une liste de candidats dans des slides.

Le recruteur doit :

- structurer les informations utiles
- faire ressortir les priorites
- synthetiser les retours d'entretien
- montrer ou en est le process
- adapter la presentation a son audience

Par exemple, une synthese pour un hiring manager ne ressemble pas a une presentation pour la direction.

Il faut parfois montrer :

- l'avancement des recrutements
- les blocages du pipeline
- les profils en short-list
- les besoins par poste
- les prochaines actions

C'est ce travail de transformation qui prend plusieurs heures chaque semaine.

## Les presentations recrutement les plus longues a produire

### 1. Les suivis de pipeline candidats

Ces decks servent a presenter :

- le nombre de candidats par etape
- les postes prioritaires
- les goulets d'etranglement
- les prochaines interviews

### 2. Les syntheses de process de recrutement

Elles permettent de montrer :

- les etapes du process
- les roles de chaque partie prenante
- les delais
- les points de validation

### 3. Les comptes rendus pour hiring managers

Ces presentations doivent etre :

- claires
- rapides a lire
- faciles a comparer

Le recruteur doit y condenser plusieurs feedbacks et recommandations.

### 4. Les revues hebdomadaires RH ou recrutement

Elles regroupent souvent :

- les recrutements ouverts
- les postes critiques
- les difficultes de sourcing
- les arbitrages a faire

## Combien de temps un recruteur passe vraiment sur PowerPoint

Prenons un cas frequent.

Un recruteur ou talent acquisition manager prepare souvent :

- 2 a 4 presentations par semaine
- 1 a 3 heures par presentation

Cela represente :

- **4 a 10 heures par semaine** sur PowerPoint

Un temps qui pourrait etre reinvesti dans :

- le sourcing
- la qualite des entretiens
- la coordination avec les managers
- l'amelioration du process
